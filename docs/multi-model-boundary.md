# Multi-Model Boundary

---

## Purpose

The LORI Multi-AI Jury System uses multiple AI perspectives to reduce single-model dominance and expose disagreement.

The public boundary defines why multi-model review matters without revealing private orchestration mechanics.

---

## Public Principles

### Role separation

Each AI role has a defined function and must avoid acting outside that function.

### Model diversity

Multiple AI systems may be used to compare reasoning patterns, detect contradiction, and reduce narrow model bias.

### Non-contamination

Role outputs should remain distinguishable so that one role does not silently absorb another role's reasoning before independent review is complete.

### Human final authority

AI model plurality does not create automatic legitimacy. Human sovereignty review remains required.

### Auditability

The public record must show role outputs, vote positions, rationale summaries, dissent, and human review status.

---

## Non-Disclosure Boundary

The public repository does not disclose:

- Model routing criteria
- Prompt containment logic
- Cross-examination sequence internals
- Anti-contamination methods
- Manipulation detection rules
- Scoring boundary calibration
- Audit memory schema
